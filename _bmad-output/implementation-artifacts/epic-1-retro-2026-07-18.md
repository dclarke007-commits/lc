## 1. Epic Summary

7 stories, all `done`:

- 1-2 Create/edit client records

- 1-4 Direct booking — cap enforcement, one-winner concurrency
- 1-5 Mark job outcome (completed / no-show)

Delivered the foundation layer: auth/session seam, client CRUD, capacity model, the booking keystone, lifecycle transitions, and the read-only forecasting surface. Every story shipped through 3-layer adversarial code review (Blind Hunter + Edge Case Hunter + Acceptance Auditor). tsc clean, full suite green at each merge.

## 2. What Went Well

- **Architecture spine held.** AD-1 (surfaces→actions→domain→db), AD-3 (pgBouncer txn-mode pooling), AD-6 (operator session ≠ client token), AD-8 (owner_id seam), AD-9 (UTC timestamptz), AR15 (`{ok,data}|{ok:false,reason}` contract, no throws across boundary) were honored consistently across all 7 stories — the seam laid in 1-1 carried the whole epic.
- **Single-source invariants.** One clock (`clock.ts`), one capacity rule (`capacity.consumesSlot`); `derive` reused both rather than re-implementing.
- **Adversarial review earned its keep.** It caught multiple HIGH defects pre-merge that dev's own tests missed (see §3).

## 3. What Was Hard / Challenges

- **Concurrency correctness (the booking keystone).** The advisory lock was keyed on `(owner, date)`, which serializes the per-day cap but NOT the cross-day weekly-14 ceiling. Dev's own concurrency tests all raced the *same date*, masking it. All 3 review layers independently flagged it as the top defect → re-keyed lock to `(owner, week-monday)`, added a discriminating cross-day weekly-race test.
- **DST correctness.** `zonedWallToUtc` mishandled nonexistent spring-forward wall times → fixed with round-trip disambiguation, regression-tested via Asia/Tehran midnight gap.
- **Idempotency replay.** Replay could return the wrong Job; fixed to require date+client match else `booking-conflict`.
- **Auth hardening surfaced late.** Session never expired server-side (`iat` ignored); email-enumeration timing (no-row path skipped scrypt); weak `SESSION_SECRET` unenforced. All fixed with tests.

## 4. Key Insights / Lessons

1. **Tests that don't discriminate hide bugs.** Same-date concurrency tests gave false confidence on a cross-day invariant. Concurrency tests must vary the axis the invariant spans.
2. **Adversarial review is load-bearing, not ceremony.** The highest-severity defects of the epic were review-caught, not dev-caught.
3. **Single-source or it drifts.** `capacity.ts` kept private copies of week arithmetic (pre-existing) — flagged as a unification follow-up rather than left silent.
