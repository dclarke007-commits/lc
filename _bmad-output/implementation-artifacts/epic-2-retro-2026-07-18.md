Delivered the AD-5 compose≠deliver seam: transport-agnostic `compose()` → `MessageDraft`, a `lib/delivery/deeplink.ts` render adapter (`wa.me`/`sms:`), and dispatch logging with `drafted_at`/`dispatched_at` + nonce idempotency. This seam is the architectural keystone reused by every downstream drafting path (Epics 3 rebooking/win-back, Epic 5 payment reminders).

## 2. What Went Well

- **The seam stayed clean.** No transport detail leaked into `compose`; templates depend only on `MessageDraft`. This is exactly what let Epics 3 and 5 reuse the path with zero template rewrite — the payoff the keystone was designed for.
- **Idempotency worked as specified.** Nonce-keyed dispatch (`confirm:${jobId}`, per-draft nonce) — re-tap does not double-log; verified by test.
- **Simplicity gate respected.** Four fixed template types, no user-addable template system built.
- **Epic 1 discipline carried forward.** Adversarial 3-layer review and single-sourced invariants continued.

## 3. What Was Hard / Challenges

- **Prototype-pollution lookup crashes — a *systemic* pattern.** Tampered `?saved=`/`?error=` keys like `__proto__` / `constructor` hit `LABELS[key]` / `ERROR_MESSAGES[key]` map lookups, returned truthy inherited objects/functions, rendered as a React child → 500. Fixed in `templateErrors.ts` and `bookingErrors.ts` with `Object.hasOwn` guards — but the identical crash is still **latent in `capacityErrors.ts`** (pre-existing from Story 1-3, logged to deferred-work).
- **Brace-leak in `resolveTemplate`.** Single-pass regex left stray braces on nested/doubled/unclosed input (`{{amount}}`→`{$5}`), risking a raw `{token}` reaching a client. Fixed with a post-substitution `[{}]` strip backstop.
- **Phantom dispatch + unbounded input.** Phoneless/tampered send-tap could log a dispatch with no deliverable link (fixed: build link before recording); `body` had no max length (fixed: 2000-char bound); amount accepted non-numeric (fixed: strict `^\d+(\.\d{1,2})?$`).
- **AC wording vs write-on-read reality.** AC1's literal "log `drafted_at` on render" conflicts with not writing to the DB on a GET; resolved by materializing the drafted row at send-tap / at commit (2-4), fatigue counter reads only `dispatched_at`. Accepted as a documented deviation.

## 4. Key Insights / Lessons

1. **The prototype-key crash is a class, not an incident.** It recurred across three error-message maps. Point fixes leave the next map exposed (capacityErrors still is). This wants one shared safe-lookup helper, not N guards.
2. **"On render" ACs collide with RSC/no-write-on-read.** Where an AC implies a side effect on a read path, resolve it at the write boundary and document the deviation — don't write on GET.
3. **A clean seam pays compounding interest.** The one-time cost of keeping transport out of `compose` bought zero-rewrite reuse across two later epics.
